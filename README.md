# 焼肉店 公式スマホアプリ「焼肉 誠」（yakiniku/）

熊本県内に3店舗を展開する焼肉店の公式スマホアプリ（プロトタイプ）。
「顧客が店を探すためのアプリ」ではなく、**お店側から次回来店のきっかけを作るアプリ**をコンセプトに、
集客 → 会員登録 → 来店 → ポイント → クーポン → 再来店 の循環を作ることを目的としています。

## 動かし方

`yakiniku/index.html` をブラウザで開くだけで動作します（データはlocalStorageに保存）。

### テスト用アカウント

| 種別 | ID | パスワード | ログイン後の画面 |
|------|-----|-----------|------------------|
| お客様 | `000` | `000` | お客様アプリ（スマホUI） |
| 管理者 | `123` | `123` | 管理画面（ダッシュボード） |

## お客様アプリの機能（下部5タブ構成）

- **ホーム**：本日のキャンペーン・おすすめメニュー・お知らせ・保有クーポン/ポイントのサマリー
- **店舗**：熊本3店舗の一覧と詳細（住所・営業時間・電話・定休日・駐車場・アクセス・地図リンク）、お気に入り店舗登録、人気ランキング・カテゴリー別メニュー（黒毛和牛/カルビ/ロース/ハラミ/ホルモン/海鮮/サイド/キッズ/デザート/ドリンク/コース）
- **予約**：店舗・日付・時間・人数・席種・コース・要望を指定して来店予約。予約の確認・変更・キャンセルにも対応
- **クーポン**：配布中クーポンの取得（平日限定・肉の日・雨の日など）、店頭提示→スタッフ確認で利用済み処理
- **マイページ**：ポイント残高、スタンプカード（来店1回=1スタンプ、10個で1,000円OFFクーポン自動発行）、お友達紹介コード（紹介者500pt・被紹介者500円OFF）、来店/ポイント/クーポン利用履歴、会員情報変更

## マーケティング機能

- **会員登録特典**：登録と同時に「初回登録500円OFF」クーポンを自動配布
- **バースデークーポン**：誕生日月の初回ログイン時に10%OFFクーポンを自動配布
- **ターゲット配信**：管理画面から「30日/60日以上未来店」「今月誕生日」「お気に入り店舗別」「相互送客（お気に入り店舗以外へ）」を対象にクーポン+プッシュ通知を一斉配信
- **プッシュ通知**：管理画面から全会員へ通知（アプリ内🔔ベルに未読バッジ表示）
- **ポイント**：100円=1ポイント。来店済み処理時に自動付与

## 管理画面の機能

- **マーケティング分析ダッシュボード**：会員数・新規会員・リピーター数・クーポン利用数のKPIと、店舗別来店数/売上・曜日別/時間帯別来店数・人気クーポン・人気メニューのグラフ、30日以上未来店顧客のリスト
- **予約管理**：日付別の予約一覧、来店済み処理（会計金額入力→ポイント/スタンプ自動付与）、予約取消
- **顧客管理**：検索、顧客詳細（履歴・保有クーポン）、来店の手動登録
- **クーポン管理**：クーポンの新規発行・停止/再開、発行数/利用数の確認、ターゲット配信
- **メニュー管理・店舗管理・お知らせ/キャンペーン投稿**

# 永瀬美容室 予約・顧客管理アプリ

美容室の「予約機能」と「顧客管理」を組み合わせたWebアプリです。

## 2つのバージョン

| フォルダ | 構成 | 用途 |
|----------|------|------|
| `salon/` | **PHP + MySQL 版（本命）** | XAMPPで動作。データはMySQLに保存され、複数の端末・ブラウザから同じデータを共有できる実用構成 |
| `index.html`（ルート直下） | localStorage 版（プロトタイプ） | ブラウザで開くだけで動く初期プロトタイプ。データはブラウザ内にのみ保存 |

## PHP + MySQL 版のセットアップ（XAMPP）

1. [XAMPP](https://www.apachefriends.org/jp/) をインストールし、コントロールパネルで **Apache** と **MySQL** を起動する
2. この `salon` フォルダを丸ごと `C:\xampp\htdocs\` にコピーする（`C:\xampp\htdocs\salon\index.html` になる配置）
3. ブラウザで **http://localhost/salon/api/install.php** を1回開く
   → データベース `nagase_salon`・テーブル・テストアカウントが自動作成される
4. **http://localhost/salon/** を開いてログイン

DB接続設定（ホスト・ユーザー名など）を変える場合は `salon/api/config.php` を編集してください。
テーブル定義のSQLは `salon/sql/setup.sql` にあります（phpMyAdminでの手動構築や提出資料にも使えます）。

## テスト用アカウント

| 種別 | ID | パスワード | ログイン後の画面 |
|------|-----|-----------|------------------|
| 管理者 | `123` | `123` | 管理者ページ（ダッシュボード） |
| お客様 | `000` | `000` | お客様ページ（新規予約） |

※ パスワードはDB上では bcrypt でハッシュ化して保存されています。

## 機能一覧

### お客様ページ
- **新規予約**：担当スタイリスト選択 → メニュー選択 → カレンダーで日付選択 → 空き時間選択 → 確認・確定
- **予約の確認**：今後の予約の一覧表示、**日時変更**、**キャンセル**
- **施術履歴**：過去の施術記録（カルテ）の閲覧
- **マイページ**：会員情報（氏名・電話・メール・パスワード）の変更

### 管理者ページ
- **ダッシュボード**：本日の予約、今後の予約数、顧客数、今月の売上
- **予約管理**：月間カレンダー（日別件数表示）から日付を選んで予約一覧を表示。キャンセル、「来店済み」処理（施術履歴を同時登録）
- **顧客管理**：顧客アカウントの新規発行・編集・削除、検索、カルテ表示
- **施術履歴**：全顧客の施術記録の一覧・検索・手動登録・削除
- **メニュー / 担当**：施術メニューとスタイリストのマスタ管理

## アピールポイント（技術要素）

- **ログイン認証**：ID / パスワード認証。パスワードは `password_hash()`（bcrypt）でハッシュ化保存、PHPセッションでログイン状態を管理、`session_regenerate_id()` によるセッション固定化攻撃対策
- **権限管理**：管理者 / お客様のロールをサーバー側でチェックし、APIレベルでアクセス制御（画面の出し分けだけでなく、APIを直接叩かれても403で拒否）
- **データベース連携**：MySQL（InnoDB）5テーブル構成。外部キー制約、論理削除、履歴の氏名スナップショットなど実務を意識した設計。SQLインジェクション対策としてPDOプリペアドステートメントを全クエリで使用
- **予約処理**：スタイリスト×日時のダブルブッキング防止。メニュー所要時間を考慮した空き判定を**サーバー側**で行い、確定時はトランザクション＋行ロック（`SELECT ... FOR UPDATE`）で同時予約の競合を防止
- **カレンダー機能**：月間カレンダー（定休日・過去日の無効化、日別予約件数バッジ）、30分刻みの空き時間表示
- **フロントエンド**：フレームワークなしの素のJavaScript（SPA構成）。`fetch` によるJSON API通信、XSS対策のHTMLエスケープ

## システム構成

```
ブラウザ (salon/index.html)
   │  fetch (JSON)
   ▼
PHP API (salon/api/)
   ├ auth.php          … ログイン / ログアウト / 会員情報変更
   ├ reservations.php  … 空き時間計算 / 予約作成・変更・キャンセル / 来店済み処理 / 統計
   ├ customers.php     … 顧客CRUD / カルテ
   ├ histories.php     … 施術履歴
   ├ master.php        … メニュー / スタイリスト管理
   ├ db.php            … PDO接続・セッション・共通ヘルパー
   └ install.php       … 初期セットアップ
   │  PDO (プリペアドステートメント)
   ▼
MySQL (nagase_salon)
   ├ users         … 会員（管理者 / お客様）
   ├ stylists      … スタイリスト
   ├ menus         … 施術メニュー
   ├ reservations  … 予約（users / stylists / menus へ外部キー）
   └ histories     … 施術履歴（カルテ）
```

## 仕様メモ

- 営業時間：10:00〜19:00（メニュー所要時間が閉店時刻に収まる時間まで受付）
- 定休日：火曜
- 予約は30分刻み。同一スタイリストの時間帯が重なる予約は不可
- 予約を「来店済み」にすると施術履歴（カルテ）が自動登録される
- 顧客を削除すると予約は削除されるが、施術履歴は氏名の記録付きで残る
