# 永瀬美容室 予約・顧客管理アプリ

美容室の「予約機能」と「顧客管理」を組み合わせたWebアプリです。
現在は **HTML 1ファイル（index.html）** で動作するローカルテスト版です。将来的にPWA化を予定しています。

## 起動方法（ローカルテスト）

`index.html` をブラウザ（Chrome / Edge / Safari など）でダブルクリックして開くだけで動作します。
サーバーやインストールは不要です。データはブラウザの `localStorage` に保存されます。

## テスト用アカウント

| 種別 | ID | パスワード | ログイン後の画面 |
|------|-----|-----------|------------------|
| 管理者 | `123` | `123` | 管理者ページ（ダッシュボード） |
| お客様 | `000` | `000` | お客様ページ（新規予約） |

## 機能一覧

### お客様ページ
- **新規予約**：担当スタイリスト選択 → メニュー選択 → カレンダーで日付選択 → 空き時間選択 → 確認・確定
- **予約の確認**：今後の予約の一覧表示、**日時変更**、**キャンセル**
- **施術履歴**：過去の施術記録の閲覧
- **マイページ**：会員情報（氏名・電話・メール・パスワード）の変更

### 管理者ページ
- **ダッシュボード**：本日の予約、今後の予約数、顧客数、今月の売上
- **予約管理**：月間カレンダー（日別件数表示）から日付を選んで予約一覧を表示。キャンセル、「来店済み」処理（施術履歴を同時登録）
- **顧客管理**：顧客アカウントの新規登録・編集・削除、検索、カルテ表示
- **施術履歴**：全顧客の施術記録の一覧・検索・手動登録・削除
- **メニュー / 担当**：施術メニューとスタイリストのマスタ管理

## アピールポイント（技術要素）

- **ログイン認証**：ID / パスワードによる認証、`sessionStorage` によるログイン状態の保持
- **権限管理**：管理者 / お客様でログイン後の画面・機能を出し分け
- **データベース連携**：`localStorage` をDBとして利用（`users` / `reservations` / `histories` / `menus` / `stylists` のテーブル構造。将来サーバDBへ差し替え可能な構成）
- **予約処理**：スタイリスト×日時のダブルブッキング防止（メニュー所要時間を考慮した空き判定）、確定直前の再チェック
- **カレンダー機能**：月間カレンダー（定休日・過去日の無効化、予約件数バッジ）、30分刻みの空き時間表示

## 仕様メモ

- 営業時間：10:00〜19:00（メニュー所要時間が閉店時刻に収まる時間まで受付）
- 定休日：火曜
- 予約は30分刻み。同一スタイリストの時間帯が重なる予約は選択不可
- 予約を「来店済み」にすると施術履歴（カルテ）が自動登録される

## データのリセット

ブラウザの開発者ツールのコンソールで以下を実行すると初期状態に戻ります。

```js
localStorage.removeItem("nagase_salon_db_v1"); location.reload();
```
